# Ink Studio 0.4.0 · 两轮 AUTO

## 默认设置和布局

- 删除颜色诱导的源码、参数、入口和处理步骤。旧偏好中的诱导字段被忽略；0.3.4 发布说明只保留为历史记录。
- 默认抖动强度 **1**、观看柔和度 **1**、自然映射 **1**、纸白保护 **0**；抖动强度对 Floyd / Stucki / Burkes 生效，其它三个控件按算法适用范围工作。控件移到调色区最下方；柔和度只对 DBS 有效，纸白保护只对 DBS / 蓝噪声有效；其它模式显示为不可用，避免误解。
- 默认画面适配为 **铺满**。应用裁切不再擅自切回“完整”；保留当前适配选择，用户仍可手动改为完整留白。铺满可能进一步居中裁剪所选区域，选屏幕比例可避免二次比例裁切。
- 新配置带 `defaultsVersion: 3`。旧配置中的显式抖动强度继续保留；新安装、重置与三个快捷预设使用满强度默认值。其它已保存调色设置继续保留；预设保留当前适配和旋转，重置恢复铺满。

## AUTO 使用

调色区顶部点击 **AUTO · 自动优化**。处理过程中显示阶段及候选进度，可立即取消；成功后参数和预览一起应用并保存，可以“撤销 AUTO”。手动调参、重置、换图或重新裁切会取消未完成的 AUTO，并使旧结果失效。AUTO 不自动发图，不改变裁切 / 旋转 / 适配，不连接外部服务。

“撤销 AUTO”恢复执行前的参数，不是多级历史；继续手动编辑或换图后该次撤销入口消失。如果没有候选得分更好，会保留当前参数，不强行改变图片。

## 两轮算法

1. **固定原图参照。** 解码、透明白底合成、裁切和缩放只做一次，在面板最终分辨率保留未经调色的 RGB。将其线性光值投影到现有理想 BWYR 色域，作为所有候选共同的参照。参照不随候选参数变化，避免把被过度简化的图自身当成正确答案。
2. **第一轮原图初调。** 分析亮度 2% / 50% / 98% 分位、近白比例、彩度和接近纯墨色的比例，生成有限幅度的亮度、对比度、Gamma 与饱和度初值。接近纯色的文字 / 色块图优先尝试直接量化，照片优先尝试 DBS。同时比较执行前参数和新默认参数，避免盲目覆盖用户已调好的效果。
3. **四色像素复评。** 对每张真实 2bpp 四色结果计算 3×3、7×7 平均后的线性颜色误差、源图边缘梯度损失、源图平坦区域的高频亮度颗粒、中性灰区域红黄点、近白背景杂点以及平均亮度偏差。原图局部方差用于区分平坦区域和细节；源图参照与边缘项用于约束“抹平图片以消噪”的错误倾向。
4. **第二轮输出驱动微调。** 根据第一轮图的平均亮度偏差微调亮度 / Gamma，根据灰区彩点调整饱和度，根据近白背景杂点有条件尝试最多 0.04 的纸白保护；同时比较柔和度、自然映射、蓝噪声或 Burkes，以及符合条件的直接量化。逐个重新生成完整分辨率像素图，并重新评分。参数组合去重，两轮合计最多 10 组。
5. **保留较优结果。** 仅当综合分数降低才替换目前最佳结果；同分保留原方案。输出参数和最终帧保持一致，PNG 导出、预览和发送来自同一张结果。

评分权重：`1.5 × fine + 3 × coarse + 0.45 × edge + 0.008 × grain + 0.025 × neutralInk + 0.035 × paperSpeckles + 0.5 × bias²`。颜色误差为 `ΔY² + 0.25[(ΔR−ΔG)²+(ΔG−ΔB)²]`。阈值和权重是本项目启发式选择，未由用户面板色度或人眼试验标定。不是训练的 AI，也不是全参数穷举；综合分降低不保证颗粒这一单项必降，更不保证所有图片的实屏观感更好。

AUTO 可以调整默认参数，但仅在点击时运行；不会持续覆盖手动设置。使用独立 isolate，取消会停止其 CPU 工作；3 分钟超时则保留原参数。其它图像处理与 AUTO 共享控制器调度，避免旧任务覆盖新帧。

## 软件检查与构建

依本轮更新后的 AGENTS.md 执行软件检查：35 项原生 C / Python 固件与 USB 模拟测试通过；41 项 Flutter 测试通过，包含未跳过的 Dart → C 固件 A0 / A1 完整帧 CRC、丢应答重试与单次刷新检查。新测试覆盖默认迁移、灰阶保持、纯色 / 细字保持、二轮综合分非退化、输出与参数一致、实际 worker 的完成 / 取消 / 错误、控制器取消和撤销。`flutter analyze --no-pub` 无问题；Windows x64 Release 与 Android Release 均编译成功。

现有 NASA astronaut 样本（来源见 `image-reconstruction.md`），768×552 默认铺满，本机 Dart JIT 单次两轮搜索比较 5 组参数，用时 2,914 ms。综合分从 0.0117363 降到 0.0109067；颗粒项从 0.0957237 降到 0.0923510，但灰区彩点占比从 0.0003420 升到 0.0012667。选择 DBS 柔和度 0.65 / 自然映射 0.8，其余默认值。这个例子展示多项权衡，不代表所有单项改善、Android 耗时或实屏效果。

可复现 AUTO 软件比较：在 `app` 执行 `dart run tool/compare_auto.dart input.png`，输出到忽略的 `build/auto-comparison/`，不触碰实体设备。该分数只是程序内部代理指标，不能代替实屏观察。

本机交付只编译，不打包：Windows `app/build/windows/x64/runner/Release/ink_studio.exe`；Android `app/build/app/outputs/apk/release/app-release.apk`。实物 USB / OTG、画面色彩和观感仍需要用户确认。
