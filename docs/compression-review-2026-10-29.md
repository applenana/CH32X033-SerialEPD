# 压缩副作用修正与图像复核（2026-10-29）

## 为什么之前是副作用

旧动态范围把每个线性 RGB 通道向 0.5 收缩，旧色域压缩重复类似操作。黑色被抬成灰色、白色被压暗，两项叠加产生全图灰雾和大量原本不需要的网点。把参数接通不等于算法合理，之前的发布说明对此描述过度。

## 重新核对开源参考

- [epdoptimize 动态范围](https://github.com/paperlesspaper/epdoptimize#dynamic-range-compression)：按面板亮度范围映射，可选百分位和纸白保护。不能将其概括成所有 RGB 通道向中点收缩。
- [epdoptimize 覆盖率](https://github.com/paperlesspaper/epdoptimize#coverage-based-bayer-and-blue-noise)：线性光混色，校准色与设备色分离。
- [epd-dither](https://github.com/Frans-Willem/epd-dither)：借鉴颜色分解与覆盖率的方向；当前 Dart 实现并非其完整移植。

本次独立实现的是保端点的温和色调曲线和四色凸包映射；不是上游 LAB 百分位动态范围算法，也未声称加入了局部色调映射。

## 当前实现

1. 动态范围：以 sqrt(Y) 为色调坐标，用端点固定的曲线调整暗部和高光。纯黑和纯白保持原值，中间亮度附近变化较小；使用同一色度缩放并限制 RGB 越界。默认 0，可按图片手动使用。
2. 色域：先求四点重心坐标。域内颜色完全不变。域外投影先校正可达亮度；滑块在此结果与“从面板黑白轴沿原色方向到达凸包边界”的结果间混合。两端均保持可达亮度，结果始终为合法四色混合。
3. 实测色板只进行一次 sRGB→线性光转换，修复此前双重转换造成的暗化。
4. 色域参数仅适用于蓝噪声和 DBS，界面明确说明。自然映射已强烈去除冷色时，色域参数变化小是正常的，不通过破坏灰阶制造可见差别。

仍需注意：这里的保色相方向是线性 RGB 中相对面板黑白轴的方向，不是严格 OKLCH 恒色相。色板有效性、光学混色假设和真实面板的非理想行为仍会限制效果。AUTO 保留参数，但尚未独立搜索这两项参数。

## 图像复核

样本：本地 NASA astronaut 图片。执行 `cd app; dart run tool/compare_compression.dart`，产生蓝噪声与 DBS 各 25 组（两参数分别为 0/0.25/0.5/0.75/1）。结果位于 `build/compression-comparison/`，未经降噪处理。

已通过图像阅读工具查看旧版两张 5×5 参数图、修订后参数图，以及最终重新生成的 DBS 0/0、0.5/0.5、1/1 原尺寸输出。观察到旧版随强度增加出现的全图灰雾已消除，头盔/衣领纯黑保持，面部和衣服层次保留。强参数仍会改变中间调和可见网点；这不等价于所有图像、人眼视距或实体屏都更优。推荐先保持 0，再按暗部是否堵塞或域外偏色情况调整。
