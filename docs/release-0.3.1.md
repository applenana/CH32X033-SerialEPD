# Ink Studio 0.3.1

本轮按用户要求只修改源码与编译，未运行 Flutter / 固件测试、静态分析、UI 自动化或实物验证；0.3.0 的验证记录不代表本版本已通过回归。

## 串口修复

- 本地 libserialport 0.3.0+1 的 API 明确规定 `timeout=0` 是无限阻塞；原先读写错误使用该值。改为 `timeout=-1`，走 `sp_nonblocking_read/write`。
- 桌面端枚举、打开、配置、读写和关闭统一放入独立 isolate，UI 不执行原生串口调用；操作由界面侧期限控制，失败后结束后台通道。若操作系统驱动自身卡在原生调用中，isolate 结束也可能要等原生调用返回，不能保证立即回收故障驱动句柄。
- 初次 INFO 识别最多等待 2 秒、不反复探测错误设备；传图阶段原有幂等重试保留。打开 / 配置由后台请求 5 秒期限限制，状态查询另有限时。
- 连接期间按钮改为“取消连接”；取消立即允许重新选择端口，过期连接结果不会覆盖新连接。无应答、异常和取消均清理候选客户端。

源码阅读结论见 [NFC 项目图像研究](nfc-image-research.md)。请由用户测试选错端口、无设备应答、端口占用、取消后重连及正常传图。
