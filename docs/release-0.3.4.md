# Ink Studio 0.3.4 · 颜色诱导实验

历史记录：用户实测效果不佳，本功能已于 0.4.0 删除。

2026-10-28。本版加入用户可手动比较的颜色诱导参数，默认关闭。不声称能还原真实蓝色或已经证实蓝感增强。按要求只编译 Windows / Android，不进行测试、静态分析、UI 检查、图像评分或实屏验证，不打包。

## 操作

- 调色区“颜色诱导 · 实验”：0–1，默认 0。0 完全绕过新增处理，保留 0.3.3 的处理路径。参数会随其它设置保存。
- 开启后显示“诱导范围（像素）”：2–24，整数步进，默认 8。这是输出图像像素的暖黄带宽度，不是实测视角或观看距离。
- 三个快捷预设和“重置所有参数”都会关闭颜色诱导，并将范围恢复为 8。
- 可以导入含蓝天、蓝色物体或青色的图片，选 DBS 或蓝噪声，固定其它参数，将强度从 0 调至 0.25–0.5，比较不同范围。没有蓝／青的图片不会产生明显变化。这个起始范围仅便于手动比较，不是最佳值结论。
- 所有六种模式都经过同一个预处理；直接量化可能将较暗的暖黄目标合并为黑白，因此空间覆盖率模式更便于观察实验网点。

## 实现范围

`app/lib/imaging/color_induction.dart` 为自行编写的启发式空间处理。颜色诱导的研究背景可参考 Kanematsu / Koida（2022），*Influence of Stimulus Size on Simultaneous Chromatic Induction*，DOI `10.3389/fpsyg.2022.818149`。论文说明背景、轮廓、空间尺寸影响颜色观感；它没有验证本算法、华为面板或下述阈值。当前实现不是论文实验图案的复现。

1. 在自然映射之前，从已经完成裁切、缩放和常规调色的 RGB 识别蓝／青。使用通道彩度、蓝相对红的优势、蓝相对绿红加权值的优势构成平滑置信度。偏紫或低彩度区域可能不会被选中；整体饱和度调为 0 后无法识别原有蓝区。
2. 对置信度大于零的区域计算两次扫描的近似欧氏内侧距离，使用水平 / 垂直代价 1 和对角代价 √2。图像边界也视为区域边界。计算和存储随像素数量线性增长，距离只需保留到范围上限。
3. 在自然映射之后，把蓝区按强度渐趋同线性亮度的中性灰，保留其明暗变化；在蓝区内部、靠近边缘的位置渐变加入暖黄色目标，外缘更强、向内部减弱。没有独立蓝区边界的整幅蓝图，会沿画布边缘出现暖带。窄小蓝区可能大部分变暖。
4. 暖色目标来自现有理想黑白黄红色域。为使暗蓝边缘有机会出现可见暖色，边带有意增加线性亮度，满强度最大增量为 0.10；这部分不是亮度守恒映射。适当放松该处的自然映射扩散保护，避免把刻意加入的暖色又全部抑制掉。
5. 实验预处理只在识别出的蓝区内部改动，不直接染黄留白或邻接肤色。后续传统误差扩散或 DBS 邻点交换仍可能影响边界附近网点，不能保证最终帧的每个边界外像素不变。
6. 暖带和中性目标交给原有重建流程生成真正的四色像素；预览、PNG 导出、原始帧及发送使用同一结果。没有只在预览上加滤镜，没有新增色号、刷新波形或固件协议。

## 取舍

可能得到冷灰观感，也可能仅出现黄边、暖色纹理、整体偏暖或窄区域细节损失；不能承诺蓝色观感。原理是假设周边暖色对比能改变对中心灰色的感受，并非通过四种墨色的面积混合产生色域外的蓝色。效果依赖原图、区域尺寸、环境光和观看距离，需要用户亲自比较。随时将强度设为 0 可关闭。
