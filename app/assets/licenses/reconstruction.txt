Ink Studio perceptual reconstruction

The DBS implementation is adapted from:
OpenDisplay/epaper-dithering packages/rust/core/src/dbs.rs
Git blob 24d92cf7f1a28ff7f5e16009ab06bed42331c6c7 (read 2026-10-28)
https://github.com/OpenDisplay/epaper-dithering
and its upstream OpenDithering src/dithering/dbs.ts (commit 2f579b9):
https://github.com/guysie/opendithering

Changes: Dart port; sequential deterministic passes; bounded pixel-scale
Gaussian model; four-color luminance-preserving gamut projection;
blue-noise initialization; coverage-preserving swaps (no ink toggles);
neutral-region, exact-ink and paper-white protection.

The blue-noise rank map is generated by this repository's own
tools/generate_blue_noise.py based on Ulichney's published void-and-cluster
method (1993); no third-party mask image is bundled.
https://cv.ulichney.com/papers/1993-void-cluster.pdf

Coverage-based decomposition was researched in epdoptimize (Apache-2.0)
and epd-dither (AGPL-3.0-only). No code or assets from those two repositories
are incorporated. Ink Studio uses a BWYR-specific weighted isotonic formula.

Natural color mapping (Ink Studio 0.3.2): original implementation inspired by
the smooth neutral/cool protection and color-candidate penalty ideas in
wiwiwei/ink-nfc-lab, src/dev/inknfclab/ResearchQuantizer.java.
https://github.com/wiwiwei/ink-nfc-lab
No Java source is incorporated. Ink Studio uses different thresholds,
linear-light luminance-preserving blending, and source-guided chromatic
error attenuation. These are heuristic settings, not panel calibration.
